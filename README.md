# Mini Bank Management System

## Project Information
- **Project Name:** Mini Bank Management System
- **Programming Language:** Java
- **Subject Code:** CEUE203
- **Subject:** Object-Oriented Programming (OOP)

## Introduction
The Mini Bank Management System is a Java-based project that demonstrates basic banking operations using Object-Oriented Programming concepts. It is developed to understand Java classes, objects, account management, and banking-related functionality.

## Features
- Bank account management
- Savings account
- Current account
- Fixed deposit account
- Deposit and withdrawal operations
- Transaction handling and statement formatting
- Input validation and custom exception handling

*Note: Features depend on the functionality implemented in the source code.*

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- GitHub for source code hosting

## Project Files
The repository contains Java source files, compiled class files, and a JAR file.

Some important Java files include:

## How to Run
1. Install the Java Development Kit (JDK).
2. Download or clone this repository.
3. Open the project folder in a terminal or Java IDE.
4. Compile the Java source files if required.
5. Run the main class according to the project setup.
